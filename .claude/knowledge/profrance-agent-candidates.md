# ProFrance — Candidatos a Agente (agent-candidates)

> NÃO criar agentes agora. Só levantar candidatos.
> Definição adotada: **agente = papel especializado com responsabilidade isolada.**
> (Skill = procedimento reutilizável; ver skill-candidates.)

---

## Como distingui-los aqui

Um agente ganha existência própria quando: (a) tem uma fronteira de responsabilidade
que não deve vazar para outras, (b) precisa manter tom/postura consistentes ao longo
de muitas interações, (c) o risco de misturar seu papel com outro é real.
